# Digital Clock ⏰

## 📌 Description
A simple and responsive Digital Clock built using HTML, CSS, and JavaScript. It displays the current time and automatically updates every second.

## 🎯 Purpose
The purpose of this project is to practice HTML, CSS, and JavaScript fundamentals and understand how JavaScript can be used to work with real-time data.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## ✨ Features
- Displays the current time
- Updates automatically every second
- Simple and clean user interface
- Responsive design


## 🚀 How to Run
1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
3. The Digital Clock will start automatically.
